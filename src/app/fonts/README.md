# JetBrains Mono

Unmodified variable Latin WOFF2 (normal, weights 100–800), recovered from this
project's successful Next.js production build. Original generated asset:
70bc3e132a0a741e-s.p.3t6q91iet4nsy.woff2 (40,480 bytes).

Upstream: https://github.com/JetBrains/JetBrainsMono
License: SIL Open Font License 1.1; see OFL.txt.

Bundled with next/font/local so development and builds use the same font without
requesting Google Fonts. Latin includes the English/Spanish UI character set;
characters outside this subset use the configured monospace system fallback.
